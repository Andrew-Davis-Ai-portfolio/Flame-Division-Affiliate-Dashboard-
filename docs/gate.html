Why this gate exists

Partner pages operate under a different standard than public marketing pages. They reference payout logic, internal processes, and partner-only tooling.

  • Protects internal language from being taken out of context.
  • Prevents random traffic from misreading partner structures.
  • Keeps affiliate and payout conversations in a controlled lane.

How access works

Once your code is accepted, this browser session stores a short-lived access token in sessionStorage. Any gated page checks for that token before loading.

Closing the browser or clearing site data will reset access and send you back to this gate.
